# ERICA 학생 혜택 UI

Figma의 [ERICA · 학생 혜택 UI](https://www.figma.com/design/M7xvW4sUaMBvKYcy0a8pRa/?node-id=129-1453)를 React Native, Expo, TypeScript로 구현한 모바일 프런트엔드입니다.

## 실행

Node.js 20.19.4 이상에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm ci
npm run web
```

Expo 개발 서버는 `npm start`, Android 에뮬레이터는 `npm run android`, macOS의 iOS 시뮬레이터는 `npm run ios`로 시작합니다. 이 프로젝트는 Expo SDK 54를 사용합니다.

## 화면 확인

| 확인할 화면 | 이동 방법 |
| --- | --- |
| 홈, 카테고리, 정렬 | 홈 상단의 칩과 추천순 버튼 |
| 검색 결과, 결과 없음 | 검색에서 `치킨덮밥` 또는 `블루베리` 입력 |
| 찜, 찜 빈 상태 | 메뉴에서 찜을 열고 카드 하트를 누르기 |
| 최근 본 항목 | 메뉴에서 최근 본 항목을 열기. 혜택 상세를 열면 목록에 추가 |
| 위치 허용, 거부 | 정렬에서 가까운 순을 선택하고 팝업에서 응답. 다른 응답을 확인하려면 앱을 다시 로드 |
| 혜택 상세, 이용 여부 | 홈에서 치킨덮밥 카드를 열고 하단 버튼 선택 |
| 종료된 혜택 | IT 필터에서 교육용 팀 이용 선택 |

혜택, 위치와 거리, 이용 여부는 화면 확인용 샘플입니다. 찜과 최근 본 항목은 앱을 다시 로드하면 초기화됩니다. 원본 썸네일, 아이콘, Pretendard 폰트는 `assets/`에 포함되어 있습니다.
